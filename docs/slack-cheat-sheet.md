# Slack Cheat Sheet

Quick reference for using Slack at the Migrants Learning Center. Print and pin, or pin in #general.

## The 5 Rules

1. Use threads. Reply in-thread to keep channels readable.
2. Keep #general for announcements only, not chatter.
3. Set your status when away or busy so people know.
4. Pick the right channel before posting (see below).
5. React to acknowledge instead of replying "got it".

## Mentions

| Mention    | Notifies                  | Use When                          |
| ---------- | ------------------------- | --------------------------------- |
| @person    | One person                | You need a specific individual    |
| @here      | Online channel members    | Timely, not urgent for everyone   |
| @channel   | All channel members       | Urgent, everyone must see it      |
