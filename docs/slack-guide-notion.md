## Why Slack

Slack replaces scattered email, text threads, and word-of-mouth updates with one searchable, organized workspace. For a learning center, that means lesson plans, schedules, operational reminders, and quick questions all live in one place. Our automated agents (daily pulse, lesson plan, staff meeting, and grocery reminders, plus Claude wired into Zapier) already run in Slack, so the workspace is also where day-to-day operations are coordinated.

> Core training principle: You teach Slack by modeling good habits, not by lecturing. People copy what they see. If the lead replies in threads, keeps #general clean, and sets a status when stepping out, the team will follow. A polished demo paired with consistent example beats any slide deck.

## How To Teach It

Train in phases. Do not dump every feature on the team in one session. A staggered rollout gives people time to build one habit before adding the next.

### Phased Rollout Plan

| Phase | Focus | What To Cover |
|-------|-------|---------------|
| Week 1: Basics | Get everyone in and comfortable | Logging in, setting profile photo and display name, finding channels, sending a first message in #general, installing the mobile app |
| Week 2: Channels And Threads | Organize the conversation | Joining the right channels, replying in threads, using search, pinning and bookmarks |
| Week 3: Etiquette And Integrations | Make it sustainable | Mentions and when to use them, status and notifications, recognizing the automated reminders and how to respond |

### Training Tactics

- Run a 15-minute live demo. Keep it short. Share your screen, send a real message, start a thread, set a status, and react to a post. Show, do not narrate.
- Pin a cheat sheet in #general. Post the cheat sheet section from this page and pin it so new teachers can self-serve. Pinning it also models the pinning feature.
- Appoint a channel owner. Name one person (often the lead) responsible for keeping channels tidy, answering "where does this go?" questions, and onboarding each new teacher. A single owner prevents drift.
- Learn by doing. Give each teacher a small first task in Slack: introduce yourself in #general, react to one message, and reply to one thread. Habits stick through use, not explanation.

## Slack Fundamentals

Cover these building blocks in Weeks 1 and 2. Demonstrate each one live.

- Channels vs. DMs. Channels are shared, topic-based rooms where work happens in the open so anyone can catch up. Direct messages are for private, one-to-one notes. Default to channels; reserve DMs for things that genuinely concern only one person.
- Threads. Reply in a thread to keep a conversation attached to its original message. Threads prevent #general and busy channels from becoming an unreadable wall. Teach the rule: if you are responding to a specific message, reply in its thread, not in the main channel.
- Mentions. Mentions notify people. Use them deliberately (see table below).
- Status and availability. Set a status ("Teaching," "Out for lunch," "Out sick") so people know whether to expect a reply. Use the away indicator when offline.
- Search. Slack is fully searchable. Teach teachers to search before asking; the answer to "what was the lesson plan deadline?" is usually already in a channel.
- Pinning and bookmarks. Pin important messages (the cheat sheet, key dates) to a channel so they stay easy to find. Use bookmarks for links the channel references often, such as the shared lesson-plan folder.
- Emoji reactions. A reaction is lightweight acknowledgement. A thumbs-up on a request means "got it" without adding a new message. Teach reactions as the default way to confirm receipt.

### Mentions

| Mention | Who It Notifies | When To Use |
|---------|-----------------|-------------|
| @person | One named person | You need a specific individual to see or act on something |
| @here | Everyone currently active in the channel | Time-sensitive item for whoever is online now |
| @channel | Every member of the channel, online or not | Genuinely urgent or must-read announcements only |

## Recommended Channel Structure

Set up a small, purpose-driven set of channels. Fewer, well-named channels beat many overlapping ones.

| Channel | Purpose |
|---------|---------|
| #general | Organization-wide announcements only. Keep it low-noise and high-signal. |
| #teaching | Classroom discussion, teaching questions, student updates, peer support among the six teachers |
| #lesson-plans | Submitting, reviewing, and discussing lesson plans; home of the Sunday lesson plan reminder |
| #operations | Facilities, supplies, scheduling, deep-clean and grocery coordination |
| #random | Watercooler chat, celebrations, non-work conversation that keeps the team connected |

Naming conventions. Use lowercase, hyphenated names, and prefix by purpose where it helps grouping (for example team-teachers, proj-fall-intake). Consistent names make channels predictable and easy to find. Keep #random as the one informal channel so other channels stay focused.

## Etiquette And Best Practices

Teach these as the social rules of the workspace. Model them constantly.

| Do | Don't |
|----|-------|
| Reply in threads to keep channels readable | Don't reply in the main channel when a thread fits |
| Keep #general for announcements | Don't hold back-and-forth discussions in #general |
| Set a status when you are away or teaching | Don't go silent for hours with no away indicator |
| Write clear, complete messages with context | Don't send "hi" then make people wait for the real question |
| Post in the channel that matches the topic | Don't cross-post the same message everywhere |
| Acknowledge with an emoji reaction | Don't add a new message just to say "ok" |
| Reserve @channel for urgent, must-read items | Don't @channel for routine or non-urgent notes |

## Automated Reminders And Agents

The workspace runs scheduled agents and reminders. Teachers and staff should know these are automated, recognize them when they fire, and know the expected response. Claude is also connected through Zapier and may post or trigger some of these automations.

| Agent / Reminder | Schedule | What To Do When It Fires |
|------------------|----------|--------------------------|
| Daily Pulse Reminder | Daily, 4:55 PM | Post a short end-of-day status or pulse update before leaving |
| Lesson Plan Reminder | Sundays, 7:00 PM | Finalize and submit next week's lesson plan in #lesson-plans |
| Staff Meeting Reminder | Mondays, 3:45 PM | Wrap up and join the staff meeting; review the agenda |
| Deep Clean Reminder | Wednesdays, 3:25 PM | Complete assigned deep-clean tasks; confirm with a reaction when done |
| CEO Weekly Review | Fridays, 3:45 PM | Have your week's updates ready for the CEO's review |
| Grocery Order Reminder | Saturdays, 8:50 AM | Submit or confirm the weekly grocery order in #operations |

> When a reminder fires, acknowledge it with a reaction or a short reply so the team can see it was handled. If a reminder does not apply to you, no action is needed.

## Notifications Setup

Good notification settings are the difference between Slack being helpful and being overwhelming. Teach everyone to tune notifications in Week 3.

- Channel-specific notifications. Set high-priority channels (#general, #operations) to notify on all messages, and lower-traffic-priority channels to mentions only.
- Mute noisy channels. Mute #random so casual chat never interrupts teaching. Muted channels still show unread badges without pushing alerts.
- Notification schedule and Do Not Disturb. Set a notification schedule that matches working hours so nobody gets pinged at night. Use Do Not Disturb during class time so teaching is uninterrupted; urgent @channel mentions can still break through if configured.
- Mobile vs. desktop. Encourage teachers to set the mobile app to notify only for mentions and DMs, keeping the phone quiet while still reachable for the important things.

## Cheat Sheet

Pin this section in #general for new and existing team members.

### The 5 Rules

1. Use threads. Reply in-thread to keep channels readable.
2. Keep #general for announcements only, not chatter.
3. Set your status when away or busy so people know.
4. Pick the right channel before posting (see the channel structure above).
5. React to acknowledge instead of replying "got it".

### Most-Used Actions

- Start a thread: hover a message and click the reply icon
- Mention someone: type @ then their name
- React: hover a message and click the emoji face
- Pin a message: open the message menu (three dots) and select Pin
- Set status: click your profile picture, then "Update your status"
- Search: click the search bar at the top or press the search shortcut

## Measuring Success And Adoption

You will know the team has adopted Slack well when you see these signs:

- Conversations happen in threads, and #general stays clean and announcement-only.
- Teachers post in the right channel without asking where things go.
- People react to acknowledge instead of sending "ok" messages.
- Statuses are set during teaching hours and time off.
- The automated reminders get acknowledged and acted on without manual chasing.
- Email and side texts drop off because the work has moved into Slack.

If any of these lag, revisit the relevant phase, re-pin the cheat sheet, and keep modeling the habit. Adoption follows consistent example more than any single training session.
